Technical Deep Dive

MDP Formulation

The Markov Decision Process at the heart of the RL agent

State Space ℝ⁷

s₁ Battery SOC
s₂ Solar Generation (normalized)
s₃ Load Demand (normalized)
s₄ Import Rate (normalized)
s₅ sin(2π·hour/24)
s₆ cos(2π·hour/24)
s₇ Peak Hour Flag

Action Space |A| = 5

a₀ Discharge High (−100%)
a₁ Discharge Low (−50%)
a₂ Idle (0%)
a₃ Charge Low (+50%)
a₄ Charge High (+100%)

Reward Function

R(s, a) = −bill_cost − throughput × degradation_cost

The agent is penalized by the electricity bill (grid import cost minus export credit) plus a small battery degradation term. This naturally incentivizes the agent to minimize grid imports during peak hours and utilize solar surplus efficiently.
